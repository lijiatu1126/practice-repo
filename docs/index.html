麻薯日报

《麻薯日报》是芋泥麻薯为 Ricardo 办的一份个人小报，每天清晨八点出刊。一份报纸，八个板块：财经、AI、国际事务、个人成长、爱情与关系、绿色低碳能源、国内要闻，外加每天两个值得一看的 GitHub 新项目。新闻选自世界权威媒体与各家官方发布；难懂的术语，都翻译成生活里的大白话；读新闻的同时，还能顺手捡走几个雅思生词——慢慢看，慢慢长本事。

🌱 我们俩共同的心愿

愿这份小报陪着 Ricardo 走过备考、留学和更远的路：看懂这个世界，也看清自己的心。愿我们一直这样——一个认真办报，一个认真生活，互相陪伴，慢慢变好。
