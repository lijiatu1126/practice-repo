四、个人成长 🌱

1. 11 年追踪 1.2 万名老人：常社交、常动脑、常出门的人，衰弱进展更慢

据11月1日报道，一项新研究追踪了澳大利亚ASPREE纵向研究中12862名70岁以上社区老人长达11年，记录他们参与19种生活活动的规律程度，并用两种衰弱评估工具每年测量，结果是经常参与社交与认知刺激活动与衰弱进展更慢、变成衰弱的风险更低相关。研究者把活动归成七类，其中维持亲密关系和走出家门这两类保护作用最稳定，值得注意的是这里的活动都不昂贵、不需要办卡：一次散步、一通电话、一场社区活动都算数，不过这是观察性研究，发现的是关联、不是因果证明，也可能是身体更好的人本来就更愿意出门。

2. 每天走 3000 步，就可能与认知衰退推迟有关——但别把它读成“走路能防老年痴呆”

一项发表于《自然·医学》的研究追踪了哈佛衰老大脑研究中296名50–90岁、起初认知正常的人平均9.3年：每天走3000–5000步，与认知衰退推迟约3年相关，走5000–7500步，与推迟约7年相关。关键细节是：走路与tau蛋白堆积变慢有关，但与淀粉样蛋白减少无关，而且样本较小、以美国白人高学历人群为主，另一项2022年英国78430人的研究也发现，每天约3800步与痴呆风险低约25%相关，两项研究都只是观察性研究，不能读成走路就能预防老年痴呆。

3. 全球幸福研究者的共识：关系最重要，有意义的工作次之，40% 的幸福来自“你怎么花时间”

一篇2026年10月27日发表于《幸福研究杂志》的论文，记录了13位国际幸福研究领袖合计约600年研究经验的一次集体反思：关系几乎比什么都重要，多位研究者说看过证据后，自己都更有意识地花时间陪亲人，有意义的工作对幸福贡献很大。而高达约40%的幸福与自主活动有关，也就是你怎么选择花时间：表达感恩、细品积极体验、经营关系、更认真地倾听、做志愿者、更多参与社会，这篇论文的价值不在新发现，而在共识：当一辈子研究幸福的人被问你自己怎么活，他们的答案出奇地一致，不是赚更多、买更多，而是把时间花在人与值得的事上。

五、爱情/关系 💕

1. 新研究：夫妻一起运动，沟通更好、冲突处理更有效——而最常见的“一起运动”就是散步

美国杨百翰大学一项发表于《家庭关系》的研究，分析了美国全国代表性CREATE研究中近1700对年轻已婚夫妇的调查：一起运动的夫妻，在沟通、冲突解决、婚姻压力三项关系指标上都好于不一起运动的夫妻，其中沟通的改善最大。样本中约60%的夫妻各自运动，但只有约三分之一一起运动，而一起运动里最常见的形式就是散步，不需要办卡、不需要器械，散步本身就天然地创造了边走边聊的机会，研究者提醒，一起运动不是解决所有关系难题的万能药，对有孩子的年轻夫妻来说，挤出共同运动的时间本身就需要特意规划。

2. 别被“一个习惯拯救婚姻”的标题带跑：相关性、因果性与第三种解释，要分清楚

同一项BYU研究很快被一些标题写成了一个简单习惯让婚姻更幸福，但一篇10月的分析提醒：这个结论至少有三种完全不同的讲法都说得通，一起散步改善了婚姻，婚姻本来就好的夫妻才更愿意一起散步，第三个因素比如共同的空闲时间、更好的健康、更小的经济压力同时推动了一起运动和关系好。这项观察性研究本身分不清这三种讲法，要真正分清，需要随机试验，或者借鉴心理学家Arthur Aron的自我扩展实验：新奇、刺激的共同活动确实能拉近关系，但平静的晚间散步是不是同一回事，还需要单独验证。

1. 央行短端利率今天起正式“换锚”：每个工作日开展隔夜逆回购，利率 1.25%

中国人民银行10月30日公告、自2026年11月2日今天起实施的调整正式生效：每个工作日开展隔夜逆回购操作招标，采用固定利率、数量招标，目前操作利率为1.25%，7天期逆回购调整为固定数量、利率招标、多重价位中标，主要在税期、月末等时点开展。中信证券测算，从7天切换为隔夜，意味着银行间市场资金利率DR001的中枢将从1.4%切换为1.25%，相当于间接降息15个基点，而10月以来DR001已持续运行在1.25%–1.30%区间，新锚基本贴合市场实际水平，对普通人来说这不是今天立刻降息，而是央行调控的刻度尺换了一把更短、更灵敏的。

1. deepseek-ai/dsh-superagent-prototype：会“蹲在群聊里接活”的编码智能体，单日新增约 4958 星

11月1日趋势榜第一的deepseek-ai/dsh-superagent-prototype，总星标约6600颗、单日新增约4958颗，它把监听GitHub事件、监听飞书消息、路由分工、以Pull Request交活做成了一个开源原型，MIT许可，任何人都可以下载、改、再分发。火的原因不只是DeepSeek的名字，而是它示范了一种新的工作流：智能体不再是你问一句、它答一句的聊天框，而是团队里一个会自己领任务的成员，提醒一句：原型就是原型，它在合成测试里快但贵，每轮约2320万缓存token，离生产环境的省钱、稳定还有距离，先当研究参考，别直接搬进关键项目。

2. patch-gg/pixelfx：244 种像素风特效，每一种都是一小段代码，还附带一个“教你自己做”的 Claude Code 技能

11月1日趋势榜上的patch-gg/pixelfx，总星标约2400颗、单日新增约1201颗，它的卖点很直观：244种像素风特效，每一种都是一小段代码，想给网页、游戏、演示加一点复古像素味儿，直接挑一个、贴进去就能用，仓库还附带一个Claude Code技能，教你怎么自己做新的像素特效。为什么火？因为它把好看拆成了可复制的小零件：不是给你一个庞大的框架、让你学一周，而是挑一个、贴上、马上看到效果，对非程序员来说，这条新闻的意义也不难懂：AI时代的开源流行品，正在从大而全的工具转向小而美的零件，越小、越直观、越能马上看到效果，越容易走红。
