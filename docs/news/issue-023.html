四、个人成长 🌱

1. 区分"忙"和"高效"的习惯：每晚花两分钟，定好第二天唯一的一件事

Medium上一篇10月18日的热文说，忙和高效从外面看一模一样，真正的分水岭在头天晚上：花两分钟，用一句话写下“明天唯一要完成的一件事”。作者举例：坚持30天的人，年底能指着30件做完的事，而另一个人只有30天“秒回的邮件”，却想不起自己干了什么。

2. 大多数习惯死在第一个"忙乱日"：给习惯准备一个"低配版"

Substack热门newsletter “Top 1% Club”说，习惯不是死于懒，而是死于没有“坏日子预案”，顶尖的人不是从不遇到糟糕的一天，区别是他们的习惯“能弯不断”：难的那天就做低配版，断了一天第二天照常回来，不搞“下周一重新开始”那套。作业很简单：给每个习惯写下它的“坏日子版本”，贴在眼睛能看到的地方，规则只有一条——绝不连续断两天。

3. 让富人更富的"无聊习惯"：每月定投，然后忘掉它

另一篇Medium热文说，富人变富靠的不是神秘股票、不是副业，而是“无聊到极致”的重复——每月同一天投一笔钱，然后别管它，背后的数学叫复利：钱赚的钱，还会继续赚钱。作者算了一笔账：每月投200美元，年化7%，30年后大约有24万美元，其中你自己只掏了7.2万，剩下的16.8万全是“钱生的钱”。

五、爱情 / 关系 💕

1. 病毒约会词"Monkey Branching"：分手前先找好下家，像猴子荡树枝不松手

最近社交平台上“monkey branching（猴子荡枝）”的搜索量暴涨，依恋关系治疗师Kayla Meyer出面警告：这是指“在结束一段关系之前，先把下一段谈好”，就像猴子荡树枝，不抓牢下一根绝不松开上一根。她说这会三方受伤：现任一边哀悼、一边怀疑“之前的一切是不是真的”，新任则在不知情中当了“创可贴”，而荡枝的人自己则用“无缝衔接”逃避了审视自己在亲密关系里的问题。

2. 月老红线 vs 依恋理论：你的依恋风格，比你找谁更影响幸福

一篇Medium长文把中国唐朝的“月老红线”传说和西方依恋理论放在一起看：一项汇总132项研究、7万多人的元分析发现，焦虑型和回避型依恋都会显著拉低关系满意度，更扎心的是，你自己的依恋风格比伴侣的依恋风格更影响你的满意度。好消息是，依恋风格不是星座，是可以练习改变的。

3. 爱是平静，依恋是焦虑：心理咨询师教你分辨"我爱你"还是"我需要你"

Happy Lab的咨询师写道，很多人分不清爱和依恋：半夜的电话、“他为什么不回我”的恐慌、一天不说话就难受，这些强烈的感觉看着像爱，其实常常是依恋在“冒充”爱。爱是平静的，和他安静坐着也舒服，不会逐字分析每条消息，依恋是焦虑的，“他会不会离开我？”“没有他我活不下去”，一句话点破：爱说“我选择你，不是因为我需要你，而是因为我珍视你”。

六、绿色低碳能源 🔋

1. 上海"十五五"定调：2030 年新型储能装机 300 万千瓦，光伏新增 500 万千瓦

10月13日，上海市政府发布《节能降碳和循环经济发展“十五五”规划》：到2030年，新型储能装机达到300万千瓦，“十五五”期间新增光伏装机500万千瓦以上，还要搞深远海风电、“风光同场”海上光伏、绿电直连和虚拟电厂。放眼全国：截至今年6月底，全国新型储能已达1.53亿千瓦，是“十四五”初期的40多倍。

2. 光伏"反内卷"要动真格了：产能调控政策将出台，组件价格划底线

10月14日，证券时报报道主管部门或将发布加强光伏产能调控的通知，同一天，光伏行业自律会议提出组件价格底线倡议，遏制恶性竞争。前三季度光伏制造端产量同比增长超40%，出口突破1500亿美元，量涨了，价格却杀得见血，10月15日世界储能大会上，宁德时代董事长曾毓群说储能正从“新能源的配套设施”升级为电力系统“不可或缺的新型基础设施”。

3. 南非 Eskom 甩出 6GW 大单：向私营资本开放风光储招标

南非国家电力公司Eskom 10月9日启动招标资格预审，向私营资本开放最高6GW的太阳能、风电和电池储能项目，11月16日截止，首批瞄准2GW光伏加1GW储能（4GWh），远期到2040年规划32GW。南非这几年饱受限电之苦，这次是把盖电站的事交给市场，用“先选合作伙伴、再逐个招标”的新玩法加速补电。

4. 哈萨克斯坦 × 阿曼：联手搞 2GW 风光 + 储能，电供数据中心

10月6日阿曼苏丹访问哈萨克斯坦期间，两国签了战略协议：哈国营能源公司Samruk-Energy和阿曼绿色能源平台O-GREEN联手开发约2GW的太阳能和风电，配电池储能，目标是给批发市场、工业用户和数据中心供应“24小时不断”的低碳电力。中亚的风光资源加中东的资金技术，这个组合是想把绿电卖到全世界。
